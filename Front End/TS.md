TypeScript is JavaScript plus a type system.

JavaScript:

```js
function add(a, b) {
  return a + b;
}
```

TypeScript:

```ts
function add(a: number, b: number): number {
  return a + b;
}
```

TypeScript helps by describing what kind of data is expected:

- strings
- numbers
- booleans
- arrays
- objects
- function parameters and return values
