# Nginx

Nginx is a high-performance web server and reverse proxy. It is one software package that can handle several backend infrastructure responsibilities.

## Common Roles

- **Web server:** Serves static files such as HTML, CSS, JavaScript, images, and downloads.
- **Reverse proxy:** Receives client requests and forwards them to backend applications.
- **Load balancer:** Distributes traffic across multiple backend servers.
- **TLS/SSL terminator:** Handles HTTPS certificates and encryption before forwarding requests internally.
- **Cache:** Stores frequently requested responses to reduce backend load and improve response time.
- **Request router:** Sends requests to different services based on domain, path, headers, or other request details.
